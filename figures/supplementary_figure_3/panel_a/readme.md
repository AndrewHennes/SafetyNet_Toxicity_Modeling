# Supplementary Figure 3a

`supplementary_figure_3a.py` calculates the per-cell and any-cell predicted-toxic counts from the shared DrugBank compound-level input. The threshold remains score ≥0.2 for predicted toxicity. Table CSV and SVG/PNG outputs are local to this panel directory.

The input schema is in `../shared/required_input_schema.json`. The script writes its current input status before analysis.
